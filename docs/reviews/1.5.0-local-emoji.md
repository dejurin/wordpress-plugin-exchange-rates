## Implemented change

The plugin bundles 259 emoji flag SVGs under `assets/flags/emoji/` and serves them
from its installed directory. Their bytes match the previously served WordPress
CDN assets. The source is an unmodified Twemoji 14.0.2 subset at commit
`7a3dad4a4da30497093dab22eafba135f02308e1`; `LICENSE-GRAPHICS` and `NOTICE.txt`
record the CC BY 4.0 graphics license, source and attribution. No Twemoji
JavaScript is bundled. The plugin readme now describes the local assets.

Only `src/Service/CurrencyTable.php`, `src/Shortcodes/Badge.php` and `readme.txt`
change among existing package files. The flag mapping, dimensions, alternative
text, loading behavior and surrounding markup are retained. The remaining 934
existing files, including CSS, JavaScript, converter, footer/modal and catalogs,
are byte-identical. No calculation, option or data-source contract changes.

The accepted WordPress 7.1.3 versus 7.2 Beta 2 difference in the modal's lightning
and rocket emoji remains a separate core-rendering behavior. This flag-asset
change preserves those modal bytes; it does not fix or newly accept that
separate core-rendering difference.

emoji cases because their selector also counted modal decoration: 22 images
instead of the intended 14 flag images. The selector was corrected in test code
only. The four emoji cases then passed at 320/1064 px in LTR/RTL, including 20
composition pixel comparisons with zero differences. Both `browser.log` and
`browser-emoji-rerun.log` are retained; the first output is not hidden or
misreported as a clean full run. No plugin fix was needed for that test error.

Actual Safari, Firefox and Google Chrome applications were checked on
`127.0.0.1:19335` at 100% zoom using Cmd+0, in LTR and RTL. Each view contained
four full/compact shortcode/native tables and two badges; all 14 flag images
decoded and used the same origin. `native/summary.json`, screenshots and native
accessibility snapshots preserve those six checks. Safari was 27.0.1 and Chrome
156.0.8078.73; the Firefox version was not recorded in this run's manifest.
These are desktop native checks, not native 390 px viewport or VoiceOver tests.
Narrow 320/1064 px coverage is provided by Chromium.

The tests use actual bundled SVGs rather than the historical synthetic external
image substitution. Asset-byte comparisons and the explicit pixel comparisons
support preserved artwork; geometry assertions alone would not establish it.
