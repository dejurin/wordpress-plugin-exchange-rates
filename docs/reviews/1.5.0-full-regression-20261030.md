## Open findings and limits

1. **Packaged readme input instructions are inaccurate.**
   [readme.txt:201](../../plugin/trunk/readme.txt#L201) says comma/space formatted
   table inputs may be read as 1. Strict validation rejects them. This wording
   predates the refinement. Recommended wording: inputs must omit thousands
   separators/currency symbols and use a period for decimals, e.g. `1000.50`.
   Fixing it changes the ZIP identity; it was not edited during the frozen run.
2. **Gettext source-line metadata needs refresh.** Eleven CurrencyTable reference
   coordinates per POT/PO file drift by one or two lines, 44 references total.
   Strings, placeholders, markup, translations and MO behavior pass. Refreshing
   references would create a new candidate and needs a new package comparison.
3. **Plugin Check is not clean.** Its five existing Footer escape-analyzer errors,
   two inherited SQL errors and 22 warnings retain the same semantic identities.
   Raw reports, moved coordinates and the inherited checker-bootstrap translation
   notice are preserved. See [finding dispositions](1.5.0-plugin-check.md).
4. **Current GitHub CI remains unverified.** The previous successful CI/artifact
   belongs to `c4f8f597…26a8`. No push, PR mutation, CI dispatch, merge or
   publication was performed. Local PHP 8.4 parity does not replace that gate.

The static readme audit also records two inherited source-display-name wording
variations. The repository README's stale current-ZIP references were corrected
as documentation only, preserving historical CI/checksums.

An initial PHP 8.4 host evidence collector included generated Playwright images;
a concurrent screenshot deletion interrupted its postcheck after all PHP checks
had passed. Restricting stability verification to tracked test inputs resolved
the collector issue without changing or rerunning plugin code. Raw evidence is
retained. Host WP-CLI dependency deprecations and isolated installation/network
warnings are also retained rather than treated as product regressions.

VoiceOver was excluded by the maintainer and was not rerun. No WCAG certification,
universal theme compatibility, live-provider freshness, production upgrade,
Core Web Vitals or Google indexing/YMYL acceptance is claimed. Synthetic fixture
success and read-only HTTP responses cannot establish those properties.
