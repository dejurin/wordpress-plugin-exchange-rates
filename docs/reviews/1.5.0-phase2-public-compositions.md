- Both converter compositions at both widths preserve doubled/zero amounts and recovery. Invalid input is recorded separately because the new accessible error is intentional.
- Registry validation passes: 36 groups, 2 pending registrations; eight registry unit tests pass. New PHP/JS/Python syntax checks and `git diff --check` pass. Registration count is not the count of open release gates.

## Reusable implementation

The stable `ER-real-site-compositions` registry entry now points to `public-runner.cjs`, `public-measure.js` and the guarded `public-fixture.php`. Six permanent JSON/CSS fixtures retain source URLs and observed environments. The [fixture guide](../../tests/acceptance/public-cases/README.md) documents preparation, execution, extension and limitations.

The adapter reconstructs public wrapper classes, widths and inherited typography, then renders both actual installed plugin versions with identical frozen data. Theme rules include generic new-element selectors and hover/focus states. It does not inject replacement footer or modal markup. The Central Bank optimizer file containing released plugin CSS is deliberately excluded, so it cannot conceal a candidate asset change. Fonts are cached and checksum-verified locally.

Early reproduction runs exposed harness defects: absolute rather than relative inherited leading, the changed B/H2 title tag being compared as a visual defect, a missing Open Sans font, and attempting to click an intentionally disabled unsupported-dialog button. These were corrected in test tooling and all configurations rerun. Failed/intermediate artifacts are retained; they are not counted as plugin failures or final acceptance.

## Open gates and limits

1. Human visual acceptance of the new footer/modal and converter borders is pending. No automated result signs off the design.
2. Sovereign's 390 px public capture was not completed after the browser viewport controller failed. Four other mobile image crops (Central Bank, Editorial RN, Morning Telegraph and Today Africa) omitted part of the widget and were rejected during report review. Their independent 390 px DOM observations remain available; the report explicitly displays a desktop public reference beside the two mobile local versions. Only Katuru currently has a complete matched mobile public screenshot. `screenshot-review.json` records these limits. No missing image is presented as verified mobile visual evidence.
3. These are component models. They preserve observed body behavior but do not prove owner-side update success, surrounding whole-page layout, optimizer/CDN cache behavior or every third-party plugin interaction. Inaccessible cross-origin stylesheet URLs remain explicitly listed; generic CSS capture cannot prove every possible future selector conflict. Today Africa's Optimole image rewriting is not cloned.
4. This new composition matrix has Chromium and in-app browser measurements. It is not a new native Safari/Firefox or VoiceOver speech receipt. The [phase-one native package evidence and remaining VoiceOver/utility recovery items](1.5.0-phase1-integrated.md) remain unchanged.
5. Phase 3 in actual LocalWP has not started. No EU/EAA/WCAG certification claim is introduced.

Phase 2 has reusable automated coverage and a reviewable comparison, but remains open for the above acceptance/coverage items. Rollback of this phase means removing only its test/documentation additions and read-only mounts from the two disposable services; no plugin/data rollback is required because the candidate source and installed package were unchanged.
