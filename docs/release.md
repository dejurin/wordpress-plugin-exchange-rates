# Проверка и упаковка

## Источник и зависимости

Весь устанавливаемый код находится в `plugin/trunk/`. Папка `vendor/` — часть опубликованного плагина и хранится в Git.
Для работы импортированного релиза запуск Composer не нужен. Не выполняйте `composer update` как часть упаковки: в исходном релизе нет `composer.lock`, поэтому повторная установка может изменить зависимости.
Обновление зависимостей и введение lock-файла требуют отдельного изменения и проверки совместимости.

## Проверки перед PR

```sh
python3 scripts/plugin.py check
python3 scripts/plugin.py lint
python3 scripts/plugin.py package
```

`check` сверяет Version в `Install.php`, Stable tag в `readme.txt`, `Plugin::VERSION`, минимальные требования и лицензию. Проверяет точный регистр имени главного файла, отсутствие symlink, `.env`, архивов и локальных файлов в дереве плагина.
`lint` требует PHP в PATH. Runtime smoke запускается по [инструкции разработки](development.md).

`package` берёт только содержимое `plugin/trunk/` и создаёт `dist/exchange-rates.<version>.zip` плюс `.sha256`.
В архиве нет дополнительного уровня `plugin/trunk/`, документации проекта, Docker, тестов и CI.
Имена файлов сортируются, время и права ZIP-записей фиксированы. Повторная сборка одинакового дерева одним и тем же Python/zlib даёт одинаковый ZIP.
После записи скрипт распаковывает архив в памяти и сравнивает все файлы с источником. Обновляются только генерируемые файлы в `dist/`.

GitHub Actions сохраняет проверенный ZIP и checksum на 14 дней. Артефакт Actions является внешней обёрткой: для установки в WordPress используйте содержащийся в нём `exchange-rates.<version>.zip`.

## Импортированная база 1.3.2

```sh
python3 scripts/plugin.py baseline
```

Команда сравнивает всё дерево с неизменяемым [манифестом официальной 1.3.2](baseline-1.3.2.json), включая лишние/отсутствующие файлы.
После намеренных изменений кода она должна сообщать различия; манифест старого релиза не переписывается для получения зелёной проверки.
Поэтому `baseline` — проверка происхождения импорта, а не обязательный тест будущих версий в CI.

SHA-256 ZIP, собранного здесь, может отличаться от ZIP WordPress.org из-за метаданных и сжатия. Доказательство равенства кода — состав файлов и их индивидуальные SHA-256.

## Выпуск и откат

Основная ветка — подтверждённое состояние проекта. Изменения проходят ветку, PR, CI и smoke.
Для следующего выпуска согласованно обновляются версия в главном файле, runtime-константа, Stable tag и changelog; имя плагина, text domain и пути установки сохраняются.
SVN-каталоги `tags/` в Git не копируются; историю хранит Git.

**Текущий процесс не публикует ничего в WordPress.org.** SVN используется только для чтения и сверки.
Публикация следующей версии — отдельная явно разрешённая операция после проверки ZIP. В этом репозитории нет автоматического SVN deployment и его секретов.

Изменения репозитория откатываются `git revert` выбранного коммита через PR, без force-push. Откат GitHub не меняет установленный плагин на сайтах и опубликованную версию WordPress.org.
