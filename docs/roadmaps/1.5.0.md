# Exchange Rates 1.5.0 working scope

Checkpoint date: 2026-10-28. Status: completed work recorded for continued development; not a final release candidate.

The maintainer selected **1.5.0** as the current target. Preserve the existing implementation and stop extending the accessibility audit into a certification project. The maintainer defined three mandatory acceptance phases on October 28 and explicitly authorized phase 2 in parallel while phase 1 remains open. See the [release acceptance contract](../acceptance/release-gates.md).

## Included in the checkpoint

1. Explicit zero handling in editable exchange-rate tables, translated accessible converter control names, and removal of the unused jQuery UI dependency.
2. Approved footer compositions for the table, converter and badge, aligned spacing, compact date actions, source abbreviations and the MIT-licensed source marker.
3. Agreed attribution destinations: FX Source for base-currency rates, converter pair landing pages, and CurrencyRate plus the base-currency link in badges. Visible service links retain the agreed rel behavior; modal links use nofollow, noopener and noreferrer.
4. Data-details modal with source, Rate date, Saved, the [ExchangeRatesWP] disclaimer marker, plugin identity/version and API attribution.
5. Visitor-local footer timestamps with UTC retained in the details. The source date and API saved date remain distinct.
6. Existing accessibility work: named fields and Swap control, live results/errors, error associations, visible keyboard focus, dialog focus handling, meaningful badge list text and a single trend description per value.
7. Hidden modal failure behavior: no inline fragment when the native dialog capability is absent or fails.
8. Relevant WordPress rendering, sanitizer, markup and browser-style fixes, with the recorded theme/browser tests.

The [checkpoint inventory](../reviews/1.5.0-checkpoint.md) distinguishes primary-repository changes from isolated-lab implementation and identifies historical test evidence. Do not describe lab-only features as already shipped.
