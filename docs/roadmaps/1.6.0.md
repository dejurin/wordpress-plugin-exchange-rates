# Exchange Rates 1.6.0 — Gutenberg blocks

Decision date: 2026-10-28. Status: planned, not implemented.

## Scope

Add three native WordPress Gutenberg blocks:

- Exchange Rates table.
- Currency Converter.
- Currency Badge.

Reuse the existing PHP calculation, validation, formatting and cached-data paths. Store display settings rather than a frozen exchange-rate snapshot. Preserve existing shortcodes, classic widgets and saved configurations.

Support posts/pages and the applicable block Widgets / Site Editor surfaces. Use scoped editor assets and repeatable initialization so rerenders and duplicate instances do not accumulate handlers, reset unrelated input or collide on IDs. Keep the declared WordPress/PHP compatibility unless a separate maintainer decision changes it.

## Acceptance

Verify insertion, configuration, duplication, undo/redo, save/reopen, frontend parity, keyboard use, localization, missing data and coexistence with legacy content. Record the selected downgrade/recovery path before shipping stored block content. Final names and attribute schemas must be reviewed before becoming public contracts.

The earlier [editor integration design](editor-integrations-reference.md) remains useful background, but its original 1.5.0 assignment, combined Elementor gate and estimates are superseded. **Elementor is not assigned to 1.6.0 by this decision.** Its release remains to be decided.

No editor code, build dependencies or version metadata are changed by this roadmap.
