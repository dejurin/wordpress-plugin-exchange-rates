# Exchange Rates 1.5.6 — focused accessibility improvements

Decision date: 2026-10-28. Status: deferred. Preserve the accessibility improvements already implemented for 1.5.0; this plan covers the additional audit findings.

## Objective

Prevent plugin-owned UI and styles from adding accessibility barriers to otherwise accessible sites. Responsibility is limited to the plugin's output, controls, settings and supported integration conditions. A whole-site certification programme, a guarantee for arbitrary themes or a legal EAA certification claim is not the objective.

## Audit baseline to reproduce

The October 28 audit observed Astra amount text at approximately 3.85:1 and source text at 4.12:1. The current badge helper selected white on #bbbbbb (approximately 1.92:1); named colors could be measured as the fallback #eeeeee while rendered with a different background. These are baseline findings, not promises about a later revision. Reproduce each before implementing the fix.

The audit also found that the converter had ARIA names without visible purpose labels, the shortcode output textarea lacked a name, and candidate-only strings remained hardcoded English. The modal keyboard and sampled 320 px layouts passed the targeted audit; do not redesign them solely to enlarge this work package.

The [1.5.0 exact-ZIP speech recheck](../reviews/1.5.0-final-recheck.md) recorded
`Changes Increase: 2.22% 2.22%` in the optional historical column. The released
1.4.2 source has the same visible value plus ARIA label structure. Keep this
refinement separate from the already fixed duplicate trend in the Price cell.
