# Exchange Rates roadmap

Maintainer decision: 2026-10-28. These are target scopes, not release or publication records.

| Version | Scope | Status |
| --- | --- | --- |
| [1.5.0](1.5.0.md) | Existing technical controls, approved footers, data-details modal, local time display and implemented accessibility improvements | Current working checkpoint; three acceptance phases defined, phase 1 in progress |
| [1.5.6](1.5.6.md) | Additional plugin-owned accessibility fixes and focused regression coverage from the October 28 audit | Deferred; implementation stopped |
| [1.6.0](1.6.0.md) | Three native Gutenberg blocks: Exchange Rates, Currency Converter and Currency Badge | Planned; not implemented |

The final instruction selects 1.5.0 as the current target. Earlier provisional version numbers in the discussion are not additional milestones. Existing accessibility improvements remain in 1.5.0; only the additional audit/remediation work moves to 1.5.6.

The prior combined editor plan is preserved as a [historical technical reference](editor-integrations-reference.md). Elementor has no assigned version. Conditional asset loading remains outside the completed checkpoint and is not assigned to a future phase without a maintainer decision.

Nothing in this roadmap changes version headers, creates a release ZIP, authorizes publication or certifies accessibility. The [development contract](../../CONTRIBUTING.md) and [release procedure](../release.md) still apply.

The [three-phase acceptance contract](../acceptance/release-gates.md) defines release gates and strict visual compatibility for existing installations.
